元素战域
ELEMENT ARENA · 无尽炼狱
六大元素构成克制环： 火 → 草 → 水 → 雷 → 风 → 土 → 火， 克制方造成伤害 +30%。

规则说明

核心资源：支援点（全队共享）

每队共享一个「支援点」池。技能需要消耗支援点，每消耗 1 点支援点，施法者本人获得 1 点大招充能； 因此放技能本身就是在为大招积能。默认设计：每个行动阶段开始时，己方获得 1 点基础支援点（部分角色的被动会额外产出）。

行动（每人每个行动阶段一次）

普攻：造成基础伤害，全队支援点 +1。
技能 1 / 技能 2：消耗支援点，造成效果并转化为等量自身充能。
待机：自身充能 +1，全队支援点 +3。
大招：达到角色的专属充能需求即可释放（各角色 8～13 点不等，见角色卡“充能 当前/需求”），不消耗支援点；释放后清空对应需求点数，溢出充能保留在进度条上。
大招无释放次数限制。只要角色充能足够，同一行动阶段可多次释放大招。

属性克制

火 → 草 → 水 → 雷 → 风 → 土 → 火。伤害方属性克制目标属性时，最终伤害 ×1.3。

物理 / 魔法双轨属性

所有角色同时拥有物理攻击/物攻（ATK）、魔法攻击/魔攻（MATK）、物理防御/物防（DEF）与魔法抗性/魔抗（MDEF）。 普攻与战士/刺客类技能按「物攻 vs 物防」结算；法师与辅助的伤害技能按「魔攻 vs 魔抗」结算；辅助治疗量主要由魔攻决定。 组队时既要看元素克制，也要考虑法系输出是否打在了高魔抗坦克身上。保底伤害：当计算伤害低于目标防御/法抗时，至少造成攻击力或魔攻5%的伤害。
装备特殊词条：🩸吸血（造成伤害时回复等量百分比生命，16层后掉落）、🔄反伤（受到伤害时反弹等量百分比伤害及少量生命百分比，30层后掉落）。

阶段流程

蓝方先行动：蓝方 4 名角色各行动一次（顺序自定）→ 敌方行动阶段 → 重复。 任意一方全灭则战斗结束。Demo 共 10 关，关卡带不同天气与可变敌方人数，均可直接挑战用于测试；通关会在选关页标记。

天气

每个关卡拥有固定天气：晴天 / 烈阳 / 暴雨 / 雷暴 / 狂风 / 沙暴 / 迷雾 / 月蚀 / 炽风暴 / 元素乱流。 天气会强化或削弱对应元素伤害、改变治疗量、加速大招充能；开战前在选关页即可查看，出战前请根据天气调整阵容。

英雄结构

每名英雄 = 固定属性 × 定位（坦克 / 战士 / 刺客 / 法师 / 辅助）+ 被动 + 普攻 + 技能1 + 技能2 + 大招。

装备掉落与养成

每通关一个 PvE 关卡都会掉落 1 件装备，装备等级即关卡等级（Lv.1～20），等级越高词条数值越高。 每件装备随机包含 3 种不同词条（生命/物攻/魔攻/物防/魔抗或对应百分比、治疗强化）。 选定关卡进入选人页后，点击右侧已出战英雄即可在页面下方调整装备并查看装备后属性；主页「装备图鉴」可查看词条范围与装备归属。每个角色最多 3 件，同件装备不可重复穿戴。

🎲 肉鸽模式 · 无尽炼狱规则

基本流程：选择4名初始角色 → 逐层挑战 → 每关结束后进入装备调整界面 → 选择是否继续下一关。共50层，通关后获得随机徽章。
敌人数量：1-15层3人，16-30层4人，31-45层5人，46-50层6人。敌方最多刷新1个坦克。
敌人成长：攻击系数=0.70+层数×0.058，血量系数=0.75+层数×0.030，防御系数=0.75+层数×0.017。人数增加时单人难度降低（4人×0.85，5人×0.75，6人×0.68）。46-50层为强度挑战关卡。

装备掉落规则

每层掉落3件装备，每件固定3个随机词条。掉落等级按层数区间随机：
• 1-3层：Lv.1-2，装备名称 白色（普通）
• 4-8层：Lv.3-4，装备名称 绿色（精良）
• 9-15层：Lv.5-6，装备名称 蓝色（稀有）
• 16-24层：Lv.7-8，装备名称 紫色（史诗）
• 25层后：Lv.9-10，装备名称 金色（传说）
词条颜色：按词条数值在对应掉落等级浮动范围内的位置分5档（0-20%白、20-40%绿、40-60%蓝、60-80%紫、80-100%金），掉落时固定不随强化变化。
特殊词条解锁：🩸吸血16层后掉落，🔄反伤30层后掉落。

装备强化与经济

强化：最高50级，成长率递减（Lv.1为8%，Lv.50为1%），强化到50级总倍数约6.94x。百分比词条成长率减半。
强化费用：10×1.05^(等级-1)，50级总费用约1984金币。
售卖：1级装备30金币，其他等级约强化总费用的110%，保证强化后售卖不亏。
金币获取：每层战斗获得20+层数×18+随机(0-29)金币。45层总金币（含售卖）约24700，可强化12个装备至50级。

徽章系统

通关50层后获得1个随机徽章，共12种不重复。每个徽章永久增幅所有角色3个属性（少量）。在主菜单「徽章图鉴」查看已获得徽章。

战斗机制

疲劳机制：第10回合后，全体造成伤害逐回合提升（防坦克互殴），治疗量逐回合降低并趋近50%。
保底伤害：当计算伤害低于目标防御/法抗时，至少造成攻击力或魔攻5%的伤害。
属性计算：最终属性=(基础值+固定值词条)×(1+百分比词条加成)。
